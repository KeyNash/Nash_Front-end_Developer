Inside the JuaDuka build +

The problem

Keep stock, money, and debt records consistent when connectivity is unreliable.

The implementation

Local checkout, barcode workflows, atomic stock updates, encrypted backups, and reports. Fixed-integer money avoids rounding errors in transaction calculations.

Current boundary

Live payment and SMS integrations are not active. Release signing, physical-device validation, and the full eight-hour soak remain open.

The project is in development; it is not presented as a publicly released retail service.
